# Byeon Yewon | Personal Portfolio

A responsive, single-page portfolio site based on the supplied portfolio PDF. It includes an introduction, a Samsung Electronics DART financial-analysis project, qualifications, and a Research & Activities section featuring the Global MOOC on the Ethics of AI certificate.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Structure

- `index.html` — page content and navigation
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and active section state
- `assets/` — portfolio visuals and a visual preview of the supplied AI ethics certificate and its Coursera verification link

No build step or package installation is required.
